# Terraria UI sprites

Original Terraria item artwork belongs to Re-Logic. These files are game artwork,
not artwork covered by this repository's code license. Download URLs are recorded
in `sources.json`. PNG files are bundled locally; the application requires no
network connection to display them. Tk uses integer nearest-neighbor zoom only.

- `Golden_Fishing_Rod.png`: Golden Fishing Rod, https://terraria.wiki.gg/wiki/Golden_Fishing_Rod
- `Master_Bait.png`: Master Bait, https://terraria.wiki.gg/wiki/Master_Bait
- `Angler_Tackle_Bag.png`: Angler Tackle Bag, https://terraria.wiki.gg/wiki/Angler_Tackle_Bag

The rod and bait slots are decorative equipment symbols, not inventory readings.
The tackle bag slot shows the number of automated reel-in actions.
The grass/dirt frame is drawn by the application using pixel rectangles.
